# Superstore Sales & Profit Analysis Dashboard

## Project Overview
This project focuses on analyzing retail sales data using Power BI.
The objective of the project is to identify business trends, customer behavior, profit patterns, and regional performance 
through data visualization and exploratory data analysis (EDA).

---

# Dataset Information
The dataset contains information related to:
- Orders
- Customers
- Products
- Sales
- Profit
- Discounts
- Regions
- Categories

Main columns used:
- Order Date
- Ship Date
- Region
- State
- Segment
- Category
- Product Name
- Sales
- Profit
- Quantity
- Discount

---

# Business Questions
The following business questions were analyzed:

1. Which state has the highest sales?
2. How much total profit does the company earn?
3. Does discount affect company profit?
4. Which state generates the highest profit?
5. Which customer segment places the most orders?
6. Which product has the highest sales?
7. Which region generates the highest sales and profit?
8. Which category contributes the most sales and profit?

---

# Dashboard Features
The dashboard includes:

- KPI Cards
- Sales Trend Analysis
- Profit Analysis
- Product Performance Analysis
- Region-wise Sales Analysis
- Customer Segment Analysis
- Interactive Slicers and Filters

---

# Key Insights

- California generated the highest sales.
- The company earned a positive overall profit.
- Higher discounts negatively affected profit in many cases.
- Consumer segment placed the highest number of orders.
- Technology category contributed the highest sales and profit.
- West region generated the highest overall sales and profit.
- Certain products generated significantly higher sales than others.
