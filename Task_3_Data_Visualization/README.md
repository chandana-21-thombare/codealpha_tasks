# Sales Dashboard using Power BI

## Project Overview
This project is an interactive Sales Dashboard created using Power BI to analyze sales performance, profit, quantity, and regional insights.

## Features
- KPI Cards
- Sales by Category
- Profit by Region
- Sales Trend Analysis
- Interactive Filters
- Map Visualization

## Tools Used
- Power BI
- Superstore Dataset

## Dashboard Insights
- West region generated highest profit
- Technology category achieved highest sales
- Sales increased significantly in 2017
- Consumer segment contributed maximum sales
- Canon imageCLASS product generated highest sales
