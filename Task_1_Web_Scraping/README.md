# Quote Insights Dashboard using Web Scraping & Power BI

## Project Overview
This project combines Python web scraping and Power BI data visualization to analyze quotes, authors, and tags from a website.

The data was scraped from a public quotes website using BeautifulSoup and stored in a CSV file. The dataset was then visualized using an interactive Power BI dashboard.

---

## Features
- Multi-page web scraping
- Extracts quotes, authors, and tags
- Creates structured CSV dataset
- Interactive Power BI dashboard
- Data visualization and analysis

---

## Technologies Used
- Python
- BeautifulSoup
- Pandas
- Requests
- Power BI

---

## Website Used
https://quotes.toscrape.com/

## Dataset Information

- Author Name
